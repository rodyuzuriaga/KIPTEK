# KIPTEK

Sistema de votación seguro y privado en Scroll zkEVM, con asistencia de IA para verificación de identidad.

## Descripción

KIPTEK es una solución de votación electrónica que mejora la transparencia y privacidad electoral en Perú, utilizando blockchain Ethereum a través de Scroll zkEVM. Incluye verificación on-chain, preservación de privacidad con ZK proofs, y usabilidad para ciudadanos.

## Características

- Votación anónima con ZK proofs (placeholder en contrato)
- Verificación de identidad asistida por IA (off-chain)
- Resultados verificables on-chain
- Interfaz amigable para usuarios

## Instalación

1. Instalar dependencias: `npm install`
2. Compilar contratos: `npm run compile`
3. Ejecutar tests: `npm run test`
4. Desplegar: `npm run deploy` (necesita PRIVATE_KEY en .env)
5. Frontend: `npm run frontend`

## Uso

Conectar wallet MetaMask, votar por candidatos, ver resultados.
